# ❤️ CoupleSync Health Journey

**"Tumbuh sehat bersama walaupun berjauhan."**

Aplikasi private khusus untuk pasangan LDR (**Ilham & Navisa**) yang ingin membangun rutinitas positif, hidup sehat, dan menjalani progress diet bersama secara transparan tanpa tekanan berlebihan.

---

## ✨ Features

### 🔐 Private Access
- **Password Protected**: Keamanan data pribadi dengan akses terkunci.
- **Couple Pairing**: Sistem sinkronisasi antar dua akun (Ilham & Navisa).
- **Private Journey**: Tidak ada fitur publik, hanya kalian berdua.

### 📊 Shared Dashboard
- **Real-time Sync**: Lihat progres pasangan secara instan.
- **Couple Streak**: Rayakan konsistensi harian bersama.
- **Relationship Motivation**: Kutipan harian yang menghangatkan suasana.

### 🏃 Health & Fitness
- **Habit Tracker**: Checklist kebiasaan sehat harian (Water, Sleep, Junk Food, etc).
- **Workout System**: Rencana latihan berbeda untuk pria (Ilham) dan wanita (Navisa).
- **Anti-Cheat System**: Timer latihan terintegrasi untuk kejujuran progres.
- **Weight Tracker**: Pantau perubahan berat badan dan total kilogram yang berhasil turun bersama.

### 💬 Couple Interaction
- **Mini Chat**: Komunikasi ringan dengan reaksi cepat (Cheer buttons).
- **Mood Tracker**: Saling memahami kondisi emosional pasangan.
- **Couple XP & Badges**: Gamifikasi perjalanan sehat kalian.

### 🤖 AI Health Assistant
- **OpenHealth Integration**: Asisten kesehatan berbasis AI yang memproses data secara lokal dan privat.
- **Health Insights**: Saran personal untuk nutrisi dan pola latihan.

---

## 🚀 Tech Stack

- **Frontend**: [React.js](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Backend**: [Firebase](https://firebase.google.com/) (Firestore, Auth, Analytics)
- **Styling**: [TailwindCSS](https://tailwindcss.com/) + Custom Glassmorphism
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

---

## 🛠️ Installation

1. Clone repository:
   ```bash
   git clone <repository-url>
   cd couplesync-health
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run development server:
   ```bash
   npm run dev
   ```
